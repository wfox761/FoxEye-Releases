# FoxEye
**Camera viewer for Frigate NVR** – a free Android app for watching your cameras, browsing and searching events, and downloading recordings from your own [Frigate](https://frigate.video/) server.

## Install

1. On your Android phone, open the [latest release](https://github.com/wfox761/FoxEye-Releases/releases/latest).
2. Under **Assets**, tap the `foxeye-….apk` file to download it.
3. Open the download and tap **Install**. If Android asks, allow your browser to install apps.
4. Open FoxEye and enter your Frigate server address, plus a username and password if your server uses them.

After that, FoxEye checks for updates on its own and offers to install new versions (**Settings → Check for updates**).

> If you had an older "Frigate" app from this developer, uninstall it once before installing FoxEye.

## Privacy

FoxEye talks only to your own Frigate server and to this page to check for updates. It collects no data.
